Win顺 改名为 **Mac顺**，目标也变成“让 Mac 用得更顺手”。文件搜索结果右边多了定位、复制、删除按钮。WinShun is now **MacShun**, built to make your Mac smoother to use. File search results now have Reveal, Copy and Delete buttons.

## 从 Win顺 升级 · Upgrading from WinShun

1. 在菜单栏图标里选“退出 Win顺”。
2. 把“应用程序”文件夹里的 **Win顺** 拖到废纸篓。
3. 下载下面的 **MacShun-0.3.0.dmg**，把 **Mac顺** 拖进“应用程序”，然后打开。

权限、设置、剪贴板历史和文件内容索引都会保留，不用重新授权。如果开着开机自动启动，以后开机启动的就是 Mac顺。

1. Quit WinShun from its menu bar icon.
2. Drag **Win顺** from Applications to the Trash.
3. Download **MacShun-0.3.0.dmg** below, drag **Mac顺** into Applications and open it.

Permissions, settings, clipboard history and the file content index carry over, so there is nothing to grant again. If launch at login was on, MacShun now starts at login instead.

## 新功能 · What's new

- 🔍 **文件搜索结果右边的按钮**：选中的、鼠标停着的那一条右边显示“定位”（在访达中显示）、“复制”（复制文件本身，可以粘贴到访达或聊天窗口里）、“删除”（移到废纸篓）。删除要点两下，免得误删。
  **Buttons on file search results**: the selected or hovered result shows Reveal (in Finder), Copy (the file itself, ready to paste into Finder or a chat) and Delete (to Trash). Delete takes two clicks, so nothing goes by accident.
- ✨ **鼠标停在按钮上有反馈**：设置窗口的侧栏、链接和按钮，鼠标停在上面时会变色或加下划线。
  **Hover feedback**: sidebar rows, links and buttons in Settings now react when the pointer is over them.

## 第一次打开 · First launch

程序还没有苹果开发者签名，第一次打开会提示“无法验证开发者”。请到 **系统设置 → 隐私与安全性**，拉到最下面点 **“仍要打开”**。

The app is not signed with an Apple Developer ID yet. On first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**.

或者在终端运行 · Or run in Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Mac顺.app"
```

校验文件完整性 · Verify the download: `shasum -a 256 -c MacShun-0.3.0.dmg.sha256`
