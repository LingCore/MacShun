Mac顺 0.8.0 新增跨设备剪贴板共享（ShunSync v1），全面升级截图自动选区、标注工具与桌面贴图，并针对长时间常驻完成待机降耗专项优化。支持运行 macOS 14 或更新版本的 Apple 芯片和 Intel Mac。
MacShun 0.8.0 introduces encrypted cross-device clipboard sharing (ShunSync v1), overhauls screenshot region detection, annotation tools, and screen pins, and significantly cuts standby power usage. It supports Apple silicon and Intel Macs running macOS 14 or later.

## 新功能 · What's new

- 🔗 新增跨设备剪贴板共享（ShunSync v1）：默认关闭、不依赖云端或账号，开启后可在局域网或虚拟局域网内与多台 Mac顺、Win顺 端到端加密同步文字、图片、文件与文件夹，支持自动发现、6 位码配对、群组邀请码及按需流式接收文件（隐藏密码条目永不同步）。
  Added encrypted cross-device clipboard sharing (ShunSync v1): off by default with no account or cloud server; when enabled, syncs text, images, files, and folders end-to-end across MacShun and WinShun devices on your LAN or virtual LAN via auto-discovery, 6-digit pairing, invite codes, and on-demand file streaming (password-manager concealed items are never synced).
- 🎯 升级截图自动选区与交互流程：新增像素级视觉 UI 识别并与系统辅助功能探测融合，支持滚轮切换层级、Tab 仅框窗口、边缘磁吸、整边拖拽与翻转、F 尺寸与比例预设、R/⇧R 最近 10 个选区、,/ . 历史回看、?/F1 快捷键浮卡、H 隐藏工具栏及默认目录静默快速保存（⌘S / ⇧⌘S）。
  Upgraded screenshot auto-detection and workflow with pixel-based UI region detection fused with Accessibility probing, scroll-wheel hierarchy switching, Tab window-only mode, visual edge snapping, edge-drag resizing/flipping, F size/aspect presets, R/⇧R recent regions (up to 10), ,/. capture history, ?/F1 shortcut hints, H toolbar toggle, and silent quick save to a default folder (⌘S / ⇧⌘S).
- 🎨 新增马赛克/高斯模糊、自由画笔、荧光笔与聚光灯标注工具，支持 1–9/0 单键切换、[/] 调节粗细或强度、Shift 锁定方圆与角度，并可在普通截图选区内按 ⇧C 一键 OCR 复制文字。
  Added mosaic/blur, freehand brush, highlighter, and spotlight annotation tools with 1–9/0 single-key switching, [/] stroke/strength adjustments, Shift constraints, and one-key ⇧C OCR text copy directly inside a capture selection.
- 📌 桌面贴图新增贴图内 OCR 取字、原地二次标注编辑、90° 旋转与水平/垂直翻转、鼠标穿透，以及从菜单栏一键恢复穿透贴图交互。
  Screen pins now support in-pin OCR text copy, in-place re-annotation, 90° rotation and horizontal/vertical flip, click-through mode, and one-click interaction restore from the menu bar.
- 🔋 待机降耗专项优化：性能监控新增 2 / 5 / 10 秒刷新间隔（默认每 5 秒且全新安装默认仅开 CPU 与内存，低电量模式自动降频），改为热传感热点抽样与菜单栏零冗余重绘；收敛剪贴板、外设与文件索引后台定时唤醒，并修复内容提取子进程回收偶发卡死的问题。
  Reduced standby energy impact: added 2 / 5 / 10 s performance monitor intervals (5 s default, CPU & memory only on fresh installs, slower in Low Power Mode) with throttled thermal sampling and deduplicated menu bar redraws; trimmed background timers for clipboard, mouse, and file indexing, and fixed an occasional hang when reaping content-extraction helper processes.

## 下载 · Download

在菜单栏选择“检查更新…”，或下载 **MacShun-0.8.0.dmg**，将 **Mac顺** 拖进“应用程序”。更新保留现有设置和剪贴板历史。

Choose Check for Updates… from the menu bar, or download **MacShun-0.8.0.dmg** and drag **Mac顺** into Applications. Updating preserves your settings and clipboard history.

```sh
shasum -a 256 -c MacShun-0.8.0.dmg.sha256
```
