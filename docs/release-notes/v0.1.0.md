## 功能 · Features

- ⌨️ **快捷键像 Windows**：Ctrl+C/V/X/Z、Alt+Tab、Alt+F4、Win+E/D/L、Home/End、访达里 F2 重命名和剪切文件。
  **Windows shortcuts**: Ctrl+C/V/X/Z, Alt+Tab, Alt+F4, Win+E/D/L, Home/End, F2 rename and cut-paste files in Finder.
- 🖱️ **鼠标像 Windows**：关闭指针加速、滚轮方向只改鼠标、按行滚动、侧键前进后退。
  **Windows mouse**: no pointer acceleration, mouse-only scroll direction, line scrolling, back/forward buttons.
- 📋 **剪贴板历史**：Win+V 呼出，支持拼音搜索。
  **Clipboard history**: Win+V, with pinyin search.

## 第一次打开 · First launch

程序还没有苹果开发者签名，第一次打开会提示“无法验证开发者”。请到 **系统设置 → 隐私与安全性**，拉到最下面点 **“仍要打开”**。

The app is not signed with an Apple Developer ID yet. On first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**.

或者在终端运行 · Or run in Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Win顺.app"
```

校验文件完整性 · Verify the download: `shasum -a 256 -c WinShun-0.1.0.dmg.sha256`
