Mac顺 0.7.1 聚焦全量稳定性加固、常驻内存瘦身与待机降耗：将 OCR、智能打码与文档提取隔离到短生命周期子进程，优化睡眠锁屏暂停与窗口/索引内存占用，并修复键鼠、文件搜索、剪贴板、截图、显示器缩放与自动更新中的多项边界问题。支持运行 macOS 14 或更新版本的 Apple 芯片和 Intel Mac。
MacShun 0.7.1 focuses on stability, lower resident memory, and reduced idle wakeups—isolating OCR, smart redaction, and document extraction into short-lived helper processes, pausing background polling during sleep or screen lock, and fixing edge cases across input, file search, clipboard, capture, display scaling, and updates. It supports Apple silicon and Intel Macs running macOS 14 or later.

## 新功能 · What's new

- 💾 OCR、智能打码与文档全文提取改为短生命周期子进程执行，完成后自动回收内存；睡眠、锁屏或切换用户时暂停后台监控与轮询，关闭设置和更新窗口后释放界面资源。
  OCR, smart redaction, and document text extraction now run in short-lived helper processes that release memory after use; background polling pauses during sleep, screen lock, or fast user switching, and closing settings or update windows frees their UI memory.
- ⚡ 加固全局事件拦截与外设热插拔稳定性，修复 Alt+Tab 按 Esc 后修饰键残留及部分快捷键误判；窗口贴边分屏改为按需监测拖拽，显著降低平时待机唤醒。
  Hardened global event interception and USB/Bluetooth device hot-plugging, fixed stuck modifier keys after pressing Esc in Alt+Tab and shortcut misclassifications, and switched window-snap drag monitoring to on-demand to cut idle wakeups.
- 🔍 文件搜索改用增量更新外接盘并自动排除临时挂载的 DMG 镜像，压缩拼音索引内存，修复自定义日期筛选偏差，并提升“调大音量”“换个网络”等口语查询系统设置的准确度。
  File search now updates external drives incrementally while ignoring mounted DMG images, shrinks pinyin index memory, fixes custom date-filter boundaries, and improves natural-language matching for system settings queries.
- 📋 剪贴板历史自动拦截超大单条文本或无效文件链接并优化跨应用粘贴焦点识别；截图保存改为异步写入不阻塞界面，超长桌面贴图支持分块绘制，滚动长图支持即时取消。
  Clipboard history guards against oversized entries and non-file URLs with better cross-app paste targeting; screenshots save asynchronously without blocking the UI, tall screen pins use tiled rendering, and scrolling capture supports instant cancellation.
- 🛡️ 修复特定显示器缩放模式识别与非 Retina 误提示，复用性能监控硬件句柄以减少开销，并加强自动更新的 HTTPS 重定向校验、子进程超时保护与检查失败提示。
  Fixed display scaling mode detection and false non-Retina hints, reused hardware handles in performance monitoring to lower overhead, and hardened in-place updates with HTTPS redirect checks, subprocess timeouts, and clearer failure status.

## 下载 · Download

在菜单栏选择“检查更新…”，或下载 **MacShun-0.7.1.dmg**，将 **Mac顺** 拖进“应用程序”。更新保留现有设置和剪贴板历史。

Choose Check for Updates… from the menu bar, or download **MacShun-0.7.1.dmg** and drag **Mac顺** into Applications. Updating preserves your settings and clipboard history.
