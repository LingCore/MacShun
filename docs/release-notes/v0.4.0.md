Mac顺 新增截图、长截图、屏幕取字和贴图。连按两下 Ctrl 还能用日常说法找 macOS 设置和工具，剪贴板历史也能按图中文字找回图片。
MacShun adds screenshots, scrolling capture, screen text recognition and floating images. Press Ctrl twice to find macOS settings and tools with everyday phrases, or search clipboard history for text inside copied images.

## 新功能 · What's new

- 📸 **截图与屏幕取字**。从菜单栏框选区域或点选窗口，添加箭头、文字、步骤序号或实心遮挡，再复制、保存或贴到屏幕。长截图可以滚动拼接并继续标注。屏幕文字在本机识别。
  **Screenshots and screen text capture.** Select an area or window from the menu bar, add arrows, text, numbered steps or solid redactions, then copy, save or pin it. Stitch and annotate scrolling screenshots. Text recognition runs on your Mac.
- 🔍 **文件与系统功能搜索**。输入“耳机连不上”可找到蓝牙设置。文件搜索新增格式和排除筛选、Quick Look、文件夹内搜索，以及在 macOS 的打开或存储面板中前往目录。
  **File and system feature search.** Try “headphones won't connect” to find Bluetooth settings. File search adds extension and exclusion filters, Quick Look, folder-scoped search, and directory navigation in macOS Open and Save dialogs.
- 📋 **从剪贴板历史找图片**。按 Mac 键盘上的 Option+V 或 Windows 键盘上的 Win+V 打开历史，搜索图片里的文字，复制识别结果或将原图贴到屏幕。
  **Find images in clipboard history.** Press Option+V on a Mac keyboard or Win+V on a Windows keyboard. Search by text in the image, copy recognized text or pin the original image to your screen.
- 🪟 **多屏拖动更顺畅**。窗口可以直接拖过显示器边界。需要在相接边缘分屏时，稍停片刻，看到预览后松手。
  **Smoother multi-display dragging.** Drag windows freely across displays. To snap at a shared edge, pause briefly and release when the preview appears.
- 🔄 **通过拾穗发布服务检查更新**。下载可依次尝试加速镜像和 GitHub，安装前校验文件大小、SHA-256 和签名。“设置 → 通用”可关闭每天最多一次的匿名装机统计。
  **Updates through the Gleaning release service.** Downloads can fall back from mirrors to GitHub and are checked for size, SHA-256 and signature before installation. The once-daily anonymous install report can be turned off in Settings → General.

## 下载 · Download

从 0.3.0 升级，可在菜单栏选择“检查更新…”。首次安装请下载 **MacShun-0.4.0.dmg** 并把 **Mac顺** 拖进“应用程序”。通用安装包支持 Apple 芯片和 Intel 芯片，需要 macOS 14 或更新版本。首次打开时，可在“系统设置 → 隐私与安全性”选择“仍要打开”。

To upgrade from 0.3.0, choose Check for Updates… in the menu bar. For a first-time install, download **MacShun-0.4.0.dmg** and drag **Mac顺** into Applications. The universal installer supports Apple Silicon and Intel on macOS 14 or later. On first launch, use Open Anyway in System Settings → Privacy & Security if prompted.

校验文件完整性 · Verify the download

```sh
shasum -a 256 -c MacShun-0.4.0.dmg.sha256
```
