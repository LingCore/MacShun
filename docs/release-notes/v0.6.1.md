Mac顺 0.6.1 改善了文件搜索的拖放、键盘操作和窄窗口布局。通用安装包支持 Apple 芯片和 Intel 芯片，需要 macOS 14 或更新版本。
MacShun 0.6.1 improves drag and drop, keyboard actions, and narrow layouts in file search. The universal installer supports Apple Silicon and Intel Macs running macOS 14 or later.

## 新功能 · What's new

- **拖出搜索结果**。从文件名或正文搜索结果中，把文件或文件夹直接拖到访达或支持接收文件的应用。
  **Drag out search results.** Drag files and folders from filename or content matches into Finder or another app that accepts file drops.
- **用键盘打开操作菜单**。按 Ctrl+O、⌘O，或点击底部的“更多操作”，打开选中项的操作菜单。用方向键和 Enter 执行操作，按 Esc 回到搜索框。
  **Open the actions menu from the keyboard.** Press Ctrl+O or ⌘O, or click More Actions in the footer. Use the arrow keys and Enter to run an action, or press Esc to return to search.
- **横向浏览文件类型**。筛选项超出窗口时，边缘会渐隐。把指针移进筛选条即可使用鼠标滚轮，或点击此时出现的箭头。触控板仍可横向滑动。
  **Scroll file type filters horizontally.** Overflowing filters fade at the edges. Hover over the strip to scroll with the mouse wheel or click the arrows that appear. Trackpad users can swipe horizontally.
- **改善面板过渡和窄窗口排版**。筛选条短暂淡入淡出，结果区高度跟随结果更新。窄窗口优先保留文件名和操作入口，系统功能、固定目录和文件结果采用一致的行布局。
  **Smoother panel transitions and clearer narrow layouts.** The filter strip fades in and out while the results area resizes as results update. Narrow panels prioritize filenames and actions, with consistent rows for system features, pinned folders, and files.

## 下载 · Download

在菜单栏选择“检查更新…”，或下载 **MacShun-0.6.1.dmg**，将 **Mac顺** 拖进“应用程序”。

Choose Check for Updates… from the menu bar, or download **MacShun-0.6.1.dmg** and drag **MacShun** into Applications.

shasum -a 256 -c MacShun-0.6.1.dmg.sha256
