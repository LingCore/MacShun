Mac顺 0.6.0 扩展了文件搜索、截图编辑和剪贴板历史。通用安装包支持 Apple 芯片和 Intel 芯片，需要 macOS 14 或更新版本。

MacShun 0.6.0 expands file search, screenshot editing, and clipboard history. The universal installer supports Apple Silicon and Intel Macs running macOS 14 or later.

## 新功能 · What's new

- **展开文件搜索**。按 Ctrl+E 查看可调整大小的面板。按文件类型、修改时间、大小和目录组合筛选，点击列标题排序，也可以保存常用筛选。中文文件名没有字面匹配时，会尝试同音查找。
  **Expanded file search.** Press Ctrl+E to open a resizable panel. Combine file type, date, size, and folder filters, sort by column, and save filters for later. Chinese filename search can fall back to homophones.
- **搜索指定目录和 SMB 共享**。可以临时搜索某个目录的文件名，也可以将目录加入全局搜索范围。已添加的 SMB 共享断开后会显示离线，重新挂载后恢复。
  **Search folders and SMB shares.** Search filenames in a folder once or add it to your global search locations. Saved SMB shares show as offline when disconnected and return after remounting.
- **截图取色和标注编辑**。按 C 复制 HEX、RGB 或 HSL 色值，用 WASD 微调光标。新增双行工具条、直线和可编辑的折线与曲线，支持多种箭头样式。文字可换行、对齐、加粗并添加底框，序号可重编号。
  **Screenshot color picking and annotation editing.** Press C to copy a HEX, RGB, or HSL value and use WASD for pixel adjustments. The two-row toolbar adds lines, editable polylines and curves, and arrowhead styles. Text supports wrapping, alignment, bold, and backgrounds. Step markers can be renumbered.
- **剪贴板分类和预览**。按文字、链接、图片或已固定筛选历史。按 ⌘Y 预览，⌘⇧C 只复制，Shift+Enter 粘贴为纯文本。
  **Clipboard filters and previews.** Filter by text, links, images, or pinned items. Press ⌘Y to preview, ⌘⇧C to copy, or Shift+Enter to paste as plain text.
- **多屏窗口与菜单栏**。打开设置、软件更新、文件搜索或剪贴板时，窗口跟随指针所在屏幕。菜单栏继续显示选定的性能读数，并保留性能监控设置入口。拾穗计划页面显示公开用户数。
  **Multi-display windows and menu bar.** Settings, software updates, file search, and clipboard history open on the display under the pointer. Selected readings remain in the menu bar, with performance settings available from the menu. The Gleaning page shows public user counts.

## 下载 · Download

在菜单栏选择“检查更新…”，或下载 **MacShun-0.6.0.dmg**，将 **Mac顺** 拖进“应用程序”。更新保留现有设置和剪贴板历史。

Choose Check for Updates… from the menu bar, or download **MacShun-0.6.0.dmg** and drag **MacShun** into Applications. Updating preserves your settings and clipboard history.

```sh
shasum -a 256 -c MacShun-0.6.0.dmg.sha256
```
