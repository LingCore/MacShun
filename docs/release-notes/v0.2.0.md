## 新功能 · What's new

- 🔍 **文件搜索（像 Everything）**：连按两下 Ctrl 弹出搜索框，边打字边出结果，支持拼音和首字母。也能搜 Word、Excel、PowerPoint、PDF、代码和文本文件里的文字，截图、照片、扫描版 PDF 里的字也能识别。可以直接粘贴路径搜，Windows 路径（`D:\资料\合同.docx`）也认。Enter 打开，Ctrl+Enter 在访达中显示；在搜索框里按 Win+V 可以把剪贴板历史里的内容填进去。
  **File search (like Everything)**: press Ctrl twice and type; pinyin works for Chinese names. It also searches text inside Word, Excel, PowerPoint, PDF, code and text files, and recognizes text in screenshots, photos and scanned PDFs. Paste a path to find a file, Windows paths included. Enter opens, Ctrl+Enter shows in Finder; Win+V inside the search bar fills in an item from clipboard history.
- 🪟 **分屏（像 Windows 11）**：Win+方向键分到半边、四分之一或最大化，拖到屏幕边缘分屏，分好一半后用贴靠助手选另一半。两块屏幕相接的边也能拖动分屏。
  **Window snapping (like Windows 11)**: Win+arrows snap to halves, quarters or full screen; drag to screen edges; Snap Assist fills the other half. Works at the edge between two displays too.
- 🖥️ **显示器页**：每块屏幕按 100%、125%、150% 这样的百分比选缩放，只列出清晰的档位；每块屏幕单独选刷新率（144 Hz、120 Hz…）。
  **Displays page**: Windows-style scaling percentages for each screen (sharp options only), and a refresh rate picker per screen.
- 🖱️ **鼠标侧键可以自己设**：两个侧键分别选后退、前进、复制、粘贴、关闭标签页、任务视图、剪贴板历史，或者录一组任意快捷键。用罗技、雷蛇等鼠标软件设置侧键的，选“不处理”，侧键原样交给它们，不会冲突。
  **Configurable side buttons**: set each side button to back, forward, copy, paste, close tab, task view, clipboard history, or any shortcut you record. If Logitech, Razer or other mouse software handles your side buttons, choose “Leave alone” so WinShun doesn't get in the way.
- 🖱️ **光标大小**：在鼠标页直接调，1 到 4 倍，退出后恢复原样。
  **Cursor size**: 1× to 4× in the mouse settings, restored when you quit.

## 第一次打开 · First launch

程序还没有苹果开发者签名，第一次打开会提示“无法验证开发者”。请到 **系统设置 → 隐私与安全性**，拉到最下面点 **“仍要打开”**。第一次用文件搜索时，系统会问能不能访问“桌面”“文稿”“下载”，点允许才能搜到里面的文件。

The app is not signed with an Apple Developer ID yet. On first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**. The first time you use file search, macOS asks for access to Desktop, Documents and Downloads; allow it so files there can be found.

或者在终端运行 · Or run in Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Win顺.app"
```
