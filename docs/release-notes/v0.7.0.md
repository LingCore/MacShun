Mac顺 0.7.0 全面升级了剪贴板历史，新增编号快贴、悬停选段、备注、来源筛选、多条合并粘贴、访达文件记录与暂停录入，并大幅提升了长列表滚动、截图标注、文件搜索与跨屏分屏的流畅度与稳定性。支持运行 macOS 14 或更新版本的 Apple 芯片和 Intel Mac。
MacShun 0.7.0 brings a major clipboard history upgrade—adding numbered quick paste, hover previews with partial paste, searchable notes, source app filters, ordered multi-item merge paste, Finder file history, and pause/resume—along with smoother scrolling, rendering, and stability across capture, file search, and window snapping. It supports Apple silicon and Intel Macs running macOS 14 or later.

## 新功能 · What's new

- 📋 剪贴板历史支持记录并恢复访达文件、添加可搜索备注、按来源应用筛选，并可从菜单栏随时暂停或恢复记录。
  Clipboard history now saves and restores Finder file references, supports searchable notes and source-app filtering, and can be paused or resumed anytime from the menu bar.
- ⚡ 支持按可见编号快速粘贴、悬停或侧边预览时选中部分文字粘贴，以及按点选顺序合并粘贴多条文字；粘贴前会自动核对原窗口与输入控件。
  Paste faster with visible row numbers, select and paste snippets inside hover or side previews, or merge multiple text entries in click order; MacShun verifies the target window and input control before pasting.
- 🎢 重构剪贴板历史列表滚动机制，数百条图文混排记录反复上下滚动也能保持流畅且无底部异常空白，同时优化后台存盘与缩略图缓存。
  Rebuilt clipboard history scrolling with native AppKit view recycling so hundreds of mixed text and image entries scroll smoothly in both directions without blank gaps, paired with background saving and instant cached thumbnails.
- 🖼️ 优化截图画布与桌面贴图渲染性能，修复 HDR/XDR 屏幕下带标注或多边形选区导出异常及超长贴图缩放问题，并降低长截图拼接的内存峰值。
  Improved screenshot canvas and screen-pin rendering, fixed annotated and polygon exports on HDR/XDR displays plus zoom limits on tall pins, and reduced peak memory usage when stitching scrolling captures.
- 🔍 提升文件搜索面板滚动与大结果集响应速度，加固外接盘弹出保护、子进程文档提取与损坏索引自动重建，并修复中文组字期间清空搜索框的同步问题。
  Made file search scrolling and large result lists more responsive, protected indexed entries when external drives unmount, hardened helper-process document extraction and index recovery, and fixed IME composition sync when clearing queries.
- 🪟 改进多屏共享边缘拖拽防抖、刘海屏与超宽屏 HiDPI 缩放档位识别、事件拦截热路径稳定性以及自动更新临时文件清理。
  Refined multi-display shared-edge snap stability, HiDPI scaling mode detection on notched and ultrawide screens, input event-tap reliability, and temporary file cleanup during in-place updates.

## 下载 · Download

在菜单栏选择“检查更新…”，或下载 **MacShun-0.7.0.dmg**，将 **Mac顺** 拖进“应用程序”。更新保留现有设置和剪贴板历史。

Choose Check for Updates… from the menu bar, or download **MacShun-0.7.0.dmg** and drag **Mac顺** into Applications. Updating preserves your settings and clipboard history.

```sh
shasum -a 256 -c MacShun-0.7.0.dmg.sha256
```
