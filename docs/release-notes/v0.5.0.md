Mac顺 0.5.0 加入菜单栏性能监控、常用项目夹和更多截图标注，修复搜索结果首行被遮挡的问题，并补充终端兼容性。
MacShun 0.5.0 adds menu bar performance readings, pinned project folders and more screenshot annotations, fixes clipped search results, and improves terminal compatibility.

## 新功能 · What's new

- 📊 **菜单栏性能监控**。查看 CPU、GPU、内存占用和芯片温度，可分别选择显示项目；每 2 秒更新，关闭后停止采集。部分机型无法读取的项目会显示“暂不可用”。
  **Menu bar performance monitor.** Choose CPU, GPU, memory usage and chip temperature readings, updated every 2 seconds. Disabled readings stop collecting; unsupported readings show “Unavailable.”
- 📂 **常用项目夹**。右键固定搜索结果中的文件夹，再次打开搜索即可进入项目内查找；Esc 返回项目列表。
  **Pinned project folders.** Pin folders from search results and open them from the empty search panel. Search inside a project and press Esc to return.
- ✏️ **更多截图标注**。新增多边形标注和锚点选区，可选颜色、线宽及文字大小；非矩形选区导出为透明背景图片。
  **More screenshot annotations.** Use polygon annotations and anchor selections, with color, stroke width and text size controls. Nonrectangular selections export with transparent backgrounds.
- 🔒 **辅助打码**。在本机查找可能的中国大陆手机号和常见邮箱，逐项确认后实心遮挡；未确认的提示框不会成为导出内容。
  **Assisted redaction.** Find possible mainland China phone numbers and common email addresses locally, then confirm solid covers individually. Unconfirmed suggestions are excluded from exports.
- 📋 **粘贴为纯文本**。右键文字历史条目可去掉来源格式，Enter 仍按原格式粘贴。复制的截图也能用 Ctrl+V 粘贴到普通应用。
  **Paste as plain text.** Remove source formatting from a text history entry's context menu; Enter keeps the original format. Copied screenshots also support Ctrl+V in regular apps.
- 📸 **改进长截图**。连续采集滚动过程中的中间帧，改善稀疏文字、空白区域和小幅滚动的拼接，完成时保留已收到的最后几帧。
  **Improved scrolling capture.** Collect intermediate frames continuously, improve stitching across sparse text and small scroll steps, and include buffered frames when finishing.

- 🔍 **修复搜索首行被遮挡**。面板展开后按实际可用高度滚动，首行名称、路径和操作按钮完整可见；兼顾紧凑窗口与返回首项的操作。([#4](https://github.com/LingCore/MacShun/issues/4))
  **Fix clipped first search results.** Scroll using the expanded panel's available height, keeping the first name, path and actions visible in compact windows and after returning to the top.
- ⌨️ **补充 Kaku 终端识别**。与其他已识别终端一样保留原生 Ctrl 操作，使用 Ctrl+Shift+C/V 复制粘贴。已验证系统终端的原生粘贴、快捷键粘贴和历史粘贴均完整保留单行及中文多行内容；其他环境的异常仍需具体复现信息。
  **Recognize the Kaku terminal.** Preserve native Ctrl operations and use Ctrl+Shift+C/V for copy and paste. Native, shortcut and history paste paths were checked with single-line and multiline Chinese text in Terminal; other environment-specific reports still need reproduction details.
- 🀄 **复核中文输入与剪贴板入口**。保留 v0.4.0 的输入法组字修复，明确 Mac 键盘 Option+V、Windows 键盘 Win+V 的历史入口；Command+V 继续用于普通粘贴。
  **Verify Chinese input and clipboard access.** Retain the v0.4.0 composition fix and clarify Option+V on Mac keyboards and Win+V on Windows keyboards for history, with Command+V for ordinary paste.

## 下载 · Download

在菜单栏选择“检查更新…”，或下载 **MacShun-0.5.0.dmg** 并把 **Mac顺** 拖进“应用程序”。通用安装包支持 Apple 芯片和 Intel 芯片，需要 macOS 14 或更新版本。设置与剪贴板历史保留。

Choose Check for Updates… from the menu bar, or download **MacShun-0.5.0.dmg** and drag **Mac顺** into Applications. The universal installer supports Apple Silicon and Intel on macOS 14 or later, preserving settings and clipboard history.

```sh
shasum -a 256 -c MacShun-0.5.0.dmg.sha256
```
