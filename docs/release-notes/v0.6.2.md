Mac顺 0.6.2 加快了启动后的首次文件搜索和大图剪贴板历史，并为菜单栏性能监控增加了图标和折线样式。支持运行 macOS 14 或更新版本的 Apple 芯片和 Intel Mac。
MacShun 0.6.2 speeds up the first file search after launch, makes clipboard history more responsive with large images, and adds icon gauges and line charts to the menu bar. It supports Apple silicon and Intel Macs running macOS 14 or later.

## 新功能 · What's new

- 🔍 启动后，扫到的文件和文件夹会分批出现在搜索结果中。从访达呼出搜索时，刚在当前目录新建或改名的文件夹也能更快找到。
  Search results appear as folders are indexed after launch. When you open search from Finder, folders you just created or renamed in the current directory are easier to find right away.
- 📁 不同项目里有同名文件时，搜索结果会显示足以区分它们的父目录。在窄面板里也能看出该选哪一个，悬停可查看完整路径。
  When projects contain files with the same name, results show the parent folders that distinguish them, even in a narrow panel. Hover over a result to see its full path.
- 💾 全文索引的常驻内存和外接盘重扫时的内存峰值更低。外接盘扫描期间仍可搜索，文件新增、改名和删除也能更快反映在结果中。
  Full-text indexing uses less memory between searches, and external drive rescans use less peak memory. You can keep searching during a scan, and results reflect file additions, renames, and deletions sooner.
- 🖼️ 连续复制大幅 PNG 或 TIFF 图片后，打开和滚动剪贴板历史更流畅。面板优先贴近文字光标打开，在文件搜索框中也能直接粘贴历史文字。
  Clipboard history opens and scrolls more smoothly after you copy several large PNG or TIFF images. The panel opens near the text cursor when available, and you can paste saved text directly into file search.
- 📈 在“设置 › 性能监控”中，可选择用图标仪表或折线显示菜单栏读数。这两种样式都支持合并显示 CPU 和 GPU，节省菜单栏空间。
  In Settings › Performance Monitor, choose icon gauges or line charts for menu bar readings. Both styles can combine CPU and GPU in one indicator to save space.

## 下载 · Download

在菜单栏选择“检查更新…”，或下载 **MacShun-0.6.2.dmg**，将 **Mac顺** 拖进“应用程序”。

Choose Check for Updates… from the menu bar, or download **MacShun-0.6.2.dmg** and drag **Mac顺** into Applications.

```sh
shasum -a 256 -c MacShun-0.6.2.dmg.sha256
```
