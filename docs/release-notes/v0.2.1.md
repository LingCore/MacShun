Download **WinShun-0.2.1.dmg** below. One universal file for **Apple Silicon and Intel** Macs, macOS 14 or later. If you have an older version, quit it and drag the new one into Applications to replace it; your settings and clipboard history are kept.

## 新功能 · What's new

- 🔍 **文件搜索结果的右键菜单**：打开、打开方式（列出能打开它的应用，默认的在最上面）、在访达中显示、复制（复制文件本身，可以粘贴到访达或聊天窗口里）、复制路径、移到废纸篓。点右键会先选中那一条。
  **Right-click menu in file search**: Open, Open With (apps that can open the file, default first), Show in Finder, Copy (the file itself, ready to paste into Finder or a chat), Copy Path, and Move to Trash. Right-clicking selects the item first.
- 📋 **剪贴板历史“全部清除”**：在面板右上角，位置和 Windows 的 Win+V 一样。点一下按钮变红，再点一下才清空，免得误点；固定的条目会保留。
  **Clear All in clipboard history**: top-right of the panel, where Windows puts it. Click once and the button turns red; click again to clear. Pinned items are kept.

## 第一次打开 · First launch

程序还没有苹果开发者签名，第一次打开会提示“无法验证开发者”。请到 **系统设置 → 隐私与安全性**，拉到最下面点 **“仍要打开”**。

The app is not signed with an Apple Developer ID yet. On first launch, go to **System Settings → Privacy & Security** and click **Open Anyway**.

或者在终端运行 · Or run in Terminal:

```bash
xattr -dr com.apple.quarantine "/Applications/Win顺.app"
```
