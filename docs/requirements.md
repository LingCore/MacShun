# 产品需求

Mac顺（MacShun）是面向 macOS 14+ 的免费开源菜单栏工具，开箱提供接近 Windows 的日常操作习惯及常用效率工具，不要求额外配置文件或账号。

## 1. 快捷键（Keyboard）

| 编号 | 要求 |
|---|---|
| K1 | 将常用 Ctrl 组合键映射为 ⌘（保留 Shift，放行 Ctrl+H/M/Q、Ctrl+`、Ctrl+Alt 与 Ctrl+Win） |
| K2 | Home/End、Ctrl+Home/End、Ctrl+方向键按词移动与按词删除；浏览器未知焦点时不误触发页面后退 |
| K3 | Alt+Tab 切换应用、Alt+F4 关闭/退出、Win+E 打开访达、Win+D 显示桌面、Win+L 锁屏、Win+S 搜索、Win+Space 切换输入法 |
| K4 | 访达内文件列表获得焦点时支持 Ctrl+X/V 剪切移动、F2 重命名、Enter 打开、Delete 移到废纸篓、Backspace 返回上一级 |
| K5 | 独立终端保留原生 Ctrl 控制键，支持 Ctrl+Shift+C/V 复制粘贴 |
| K6 | 远程桌面与虚拟机（含 UU远程、ToDesk、向日葵）内透传原生按键 |
| K7 | Option+V（Mac 键盘）或 Win+V（Windows 键盘）呼出剪贴板历史 |
| K8 | 自动按键盘学习 Windows / Mac 键位模式，并支持在设置中按设备调整 |

## 2. 鼠标（Mouse）

| 编号 | 要求 |
|---|---|
| M1 | 按设备关闭指针加速（线性移动），支持超出系统滑块上限的指针速度倍率 |
| M2 | 仅反转普通鼠标滚轮方向（与 Windows 一致），保持触控板与妙控鼠标自然滚动 |
| M3 | 滚轮按固定行数滚动（默认每格 3 行），去除滚动加速 |
| M4 | 鼠标侧键（第 4/5 键）默认支持全应用前进/后退，可按键改为常用操作、自定义 Windows 快捷键或设为“不处理” |
| M5 | Ctrl+滚轮转换为缩放快捷键（⌘= / ⌘-） |
| M6 | 设置页直接调节光标大小（1–4 倍），优先同步系统指针大小，无完全磁盘访问权限时运行时生效并在退出后恢复 |

## 3. 剪贴板历史（Clipboard）

| 编号 | 要求 |
|---|---|
| C1 | 热键或菜单呼出面板，贴靠文件搜索栏、文字光标或鼠标，按空间上下展开，搜索框靠近弹出位置；核对目标后粘贴，支持数字键快贴、纯文本与选段粘贴、多条文字按选择顺序合并粘贴、仅复制及回填文件搜索框 |
| C2 | 支持按原文、全拼和首字母搜历史，含图片识别文字与条目备注 |
| C3 | 记录文本、富格式、图片与本机文件引用，支持按类型、来源应用或已固定筛选，支持悬停与侧边预览（⌘Y）、固定与确认后清空未固定条目 |
| C4 | 自动跳过密码管理器标记为隐藏的剪贴板条目；可从菜单栏暂停录入，恢复后从下一次复制开始记录 |
| C5 | 历史记录仅保留在本机，不上传 |

## 4. 文件与系统功能搜索（FileSearch）

| 编号 | 要求 |
|---|---|
| F1 | 连按两下 Ctrl 弹出胶囊搜索框（已打开时保持前置）；支持拼音/首字母、同音回退、路径粘贴（含 Windows 路径）、文件筛选语法与结果拖出 |
| F2 | 本地 SQLite FTS5 全文搜索常见文本、代码、配置、Office 文档及 PDF，并对图片和扫描版 PDF 执行本机 OCR；Tab 切换搜索范围 |
| F3 | 同框支持用日常中文口语、功能名、拼音或 Windows 叫法检索 macOS 系统设置与实用工具 |
| F4 | 支持 Ctrl+E 展开面板组合筛选与排序、常用筛选保存、目录内搜索（⌘F）、常用项目夹固定、外接盘/已挂载 SMB 索引，以及在原生打开/存储面板中快速跳转目录 |

## 5. 截图与贴图（Capture）

| 编号 | 要求 |
|---|---|
| S1 | 框选或点选窗口截图，支持放大镜实时取色（HEX/RGB/HSL）、WASD 与方向键像素级微调、按 R 恢复上次区域 |
| S2 | 提供矩形、椭圆、箭头、直线/折线/曲线、文字、自动递增步骤序号、多边形、锚点选区（透明导出）及实心遮挡，支持撤销重做与辅助打码（本机识别手机号与邮箱） |
| S3 | 支持连续滚动拼接长截图，并在预览阶段二次滚动标注 |
| S4 | 支持选区文字本机 OCR 复制，以及将截图或剪贴板图片贴到桌面悬浮置顶（支持缩放、透明度与右键操作） |

## 6. 显示器与分屏（Display & Window）

| 编号 | 要求 |
|---|---|
| D1 | 每块显示器单独按 Windows 百分比选择文字清晰的缩放档位 |
| D2 | 每块显示器在当前分辨率下单独选择刷新率 |
| W1 | Win+方向键实现 Windows 11 风格半屏、四分之一、最大化、恢复/最小化、跨屏移动与垂直拉伸 |
| W2 | 拖动窗口至屏幕边缘或四角分屏；多屏之间自由跨屏拖拽，共享边缘短暂停留后触发预览；自动检测与系统自带边缘平铺的冲突 |
| W3 | 半屏后弹出贴靠助手（Snap Assist）选择填充另一半的窗口 |

## 7. 性能监控（Performance）

| 编号 | 要求 |
|---|---|
| P1 | 菜单栏每 2 秒显示可选的 CPU、GPU、内存占用和芯片温度（本机采集，无需提权，关闭项停止采样） |
| P2 | 支持文字读数、纯图标仪表和折线走势三种菜单栏样式，图表样式支持合并显示 CPU 与 GPU |

## 8. 更新、本地化与分发

- **非沙盒通用安装包**：支持 macOS 14+（Apple Silicon 与 Intel 通用包）；不上架 Mac App Store（沙盒会限制全局键鼠拦截与窗口控制）。待接入 Developer ID 签名与公证前，README 明确提供首次运行放行说明。
- **自动更新与统计**：通过拾穗发布服务检查版本，按加速镜像优先、GitHub 兜底下载安装包，强制校验大小、SHA-256 与同证书签名后原地替换；提供可关闭的每日一次匿名装机统计。
- **界面语言与搜索**：完整提供简体中文与英文界面，设置窗口支持拼音检索选项。
