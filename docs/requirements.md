# 需求

整理日期：2026-10-02。需求来自作者在自用中发现的问题，以及对现有工具（Karabiner-Elements、LinearMouse、Maccy 等）的调研。

## 1. 快捷键像 Windows

| 编号 | 要求 |
|---|---|
| K1 | Ctrl+字母、数字、符号代替 ⌘+同一个键（复制、粘贴、剪切、撤销、保存、全选、查找等）；Ctrl+Y 是重做 |
| K2 | Home/End 跳到行首行尾，Ctrl+Home/End 跳到文档首尾，Ctrl+←/→ 按词移动，Ctrl+Backspace 删除一个词，以上按住 Shift 时同时选中文字 |
| K3 | Alt+Tab 切换，Alt+F4 关闭，Win+E 打开 Finder，Win+D 显示桌面，Win+L 锁屏，Win+S 搜索 |
| K4 | Finder 里：Ctrl+X 加 Ctrl+V 剪切移动文件，F2 重命名，Enter 打开，Delete 移到废纸篓，Backspace 返回上一级；光标在输入框里时不改写 |
| K5 | 在终端里不改写 Ctrl 组合键，终端改用 Ctrl+Shift+C/V 复制粘贴 |
| K6 | 在远程桌面和虚拟机里不改写任何按键，包括国产远程工具（UU远程、ToDesk、向日葵） |
| K7 | Win+V 呼出剪贴板历史（见 C1） |
| K8 | 提供“Windows 键盘 / Mac 键盘”两种布局选项，两种键盘上 Ctrl、Option、Command 的位置不同 |
| K9 | 检查与常用软件的快捷键冲突：微信、QQ、钉钉、搜狗输入法、微信输入法 |
| ~~K10~~ | ~~Caps Lock 只管大写~~（2026-10-03 试过后去掉：macOS 切换输入法时会自动关掉 Caps Lock，做不到比系统默认的“按住锁定大写”更好用） |

## 2. 鼠标像 Windows

| 编号 | 要求 |
|---|---|
| M1 | 指针没有加速（线性），指针速度可以调，比系统设置最快的 3 倍还快；都可以按设备分别设置 |
| M2 | 滚轮方向和 Windows 一致，可以按设备分别设置，不影响触控板 |
| M3 | 滚轮按行滚动（Windows 默认每格 3 行），没有滚动加速 |
| M4 | 鼠标侧键（第 4、5 键）在 Finder 等所有应用里都能前进、后退 |
| M5 | Ctrl+滚轮缩放网页和文档（待调研 macOS 上的现状） |
| M6 | 光标大小可以在鼠标设置里直接调（1 到 4 倍），退出时恢复系统设置的大小 |

## 3. 剪贴板历史

| 编号 | 要求 |
|---|---|
| C1 | Win+V 呼出，在光标附近弹出，选中后直接粘贴 |
| C2 | 支持中文拼音全拼和首字母搜索，例如输入 “jtb” 能搜到 “剪贴板” |
| C3 | 记录文字和图片，可以固定常用条目 |
| C4 | 自动跳过密码管理器标记为隐藏的内容 |
| C5 | 内容只保存在本机，不联网，不需要账号 |

## 4. 发布要求（给别人用时）

- 用 Developer ID 签名，并交给 Apple 公证。
- 不上架 Mac App Store，因为商店版要运行在沙盒里，改键和鼠标功能会受限。
- 用 Sparkle 做自动更新。国内下载另外准备渠道。
- 最低支持 macOS 14。同时支持 Intel 和 Apple Silicon（开发期间先只编译 Apple Silicon）。

## 4.4 文件搜索

| 编号 | 要求 |
|---|---|
| F1 | 连按两下 Ctrl 弹出胶囊搜索框，按文件名搜索，支持拼音和首字母；Enter 打开，Ctrl+Enter 在访达中显示（2026-10-03 用户要求）；可以粘贴路径搜（相对路径、访达里显示的文件夹名、~/、完整路径、Windows 的 D:\ 路径），文件夹对不上时名字对上的照样列出；搜索框开着时再连按两下 Ctrl 不关（2026-10-03 用户要求） |
| F2 | 同一个搜索框也按文件内容搜：txt、md、csv、json、docx、xlsx、pptx、pdf，以及代码、配置、字幕文件，图片和扫描版 PDF 里的文字（系统文字识别）（2026-10-03 和聚焦对比后加上）；常打开的文件排在前面；结果显示匹配的那一行，文件名结果在前（2026-10-03 用户要求）。搜索框右边选范围：全部 / 文件 / 内容，每次打开默认“文件”，Tab 切换（2026-10-03 用户要求） |

## 4.5 显示器

| 编号 | 要求 |
|---|---|
| D1 | 每块显示器单独选缩放，按 Windows 的百分比显示，只列出文字清晰的档位（2026-10-03 用户要求） |
| D2 | 每块显示器单独选刷新率，列出当前分辨率下系统给的所有刷新率；只有一个时不给选（2026-10-03 用户要求） |

以后可以考虑：给 2K 这类非高分屏补上清晰的 125%、150%（需要 BetterDisplay 那样的虚拟高分屏，工作量大，暂不做）。

## 4.6 分屏

| 编号 | 要求 |
|---|---|
| W1 | Win+方向键按 Windows 11 的规则分屏：←/→ 半边，半边时 ↑/↓ 变四分之一，反方向恢复，同一方向再按移到隔壁屏幕；↑ 最大化、↓ 恢复或最小化；Win+Shift+←/→ 移到另一块屏幕，Win+Shift+↑ 拉高（2026-10-03 用户要求，参考 Rectangle 但要更好） |
| W2 | 拖到屏幕边缘分屏：左右边半边，上边最大化，四个角四分之一，拖动时显示要放到哪里；拖动分着屏的窗口恢复原来的大小。两块屏幕相接的边也能分屏：拖过去时光标在边上停一下（像 Windows），继续往外推才过到另一块屏幕。和 macOS 15 起系统自带的拖动分屏冲突，系统的开着时让给系统，设置里一键关掉 |
| W3 | 贴靠助手：分到左右半边后，在另一半列出其他窗口，点一个（或方向键加 Enter）放进去 |

以后可以考虑：贴靠布局（Win+Z 选三分之一、四分之一等布局）、四分之一分屏后的贴靠助手、窗口缩略图（需要屏幕录制权限）。
